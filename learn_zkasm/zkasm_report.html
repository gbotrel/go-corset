1. Introduction to zkASM

zkASM (Zero-Knowledge Assembly) is a low-level language for writing arithmetic constraints that compile to zero-knowledge proofs. It's part of the go-corset toolchain developed by Consensys.

Key Features

  • Lisp-inspired assembly syntax
  • Variable-width integer types (u1, u8, u16, u32, u256, etc.)
  • Automatic overflow handling with multi-value returns
  • Conditional branching and control flow
  • Compiles to AIR (Arithmetic Intermediate Representation)
  • Support for multiple finite fields (BLS12-377, KoalaBear, GF(8209))

Installation

Build go-corset from source bash 
# Clone and build
git clone https://github.com/consensys/go-corset
cd go-corset
make build

# The binary is at ./bin/go-corset

3. Example 1: Cubic Polynomial (x^3 + x + 5 = Y)

Problem: Prove knowledge of a secret value x such that x^3 + x + 5 = Y, where Y is public.

gnark (Go)

example_gnark2.go go 
type Circuit struct {
    X frontend.Variable `gnark:"x"`
    Y frontend.Variable `gnark:",public"`
}

func (c *Circuit) Define(api frontend.API) error {
    // x^3
    x3 := api.Mul(c.X, c.X, c.X)
    // x^3 + x + 5
    res := api.Add(x3, c.X, 5)
    // Assert Y == res
    api.AssertIsEqual(c.Y, res)
    return nil
}

zkASM

cubic_polynomial.zkasm zkasm 
;; Prove: x^3 + x + 5 == Y
fn cubic(x u16, Y u16) -> () {
   var x2 u16
   var x3 u16
   var sum1 u16
   var result u16
   var diff u16
   var tmp u32
   var c u1

   ;; x^2 = x * x
   tmp, x2 = x * x
   ;; x^3 = x^2 * x
   tmp, x3 = x2 * x
   ;; sum1 = x^3 + x
   c, sum1 = x3 + x
   ;; result = sum1 + 5
   c, result = sum1 + 5

   ;; Assert Y == result
   c, diff = Y - result
   if diff == 0 goto success
   fail
success:
   return
}

4. Example 2: RSA Factorization Proof

Problem: Prove knowledge of secret factors P and Q such that P * Q = RSA, where RSA is public and both P != 1 and Q != 1 (non-trivial factorization).

gnark (Go)

example_gnark1.go go 
type Circuit struct {
    P   frontend.Variable // secret
    Q   frontend.Variable `gnark:"q,secret"`
    RSA frontend.Variable `gnark:",public"`
}

func (c *Circuit) Define(api frontend.API) error {
    // Ensure P != 1 and Q != 1
    api.AssertIsDifferent(c.P, 1)
    api.AssertIsDifferent(c.Q, 1)

    // Compute P * Q
    rsa := api.Mul(c.P, c.Q)

    // Assert P * Q == RSA
    api.AssertIsEqual(c.RSA, rsa)
    return nil
}

zkASM

rsa_factor.zkasm zkasm 
;; Prove: P*Q == RSA, P!=1, Q!=1
fn rsa_factor(P u16, Q u16, RSA u16) -> () {
   var product u16
   var tmp u32
   var diff u16
   var c u1

   ;; Assert P != 1
   c, diff = P - 1
   if diff != 0 goto p_valid
   fail

p_valid:
   ;; Assert Q != 1
   c, diff = Q - 1
   if diff != 0 goto q_valid
   fail

q_valid:
   ;; product = P * Q
   tmp, product = P * Q
   ;; Assert RSA == product
   c, diff = RSA - product
   if diff == 0 goto success
   fail

success:
   return
}

5. Testing zkASM Programs

Test File Format (.accepts)

Test cases are JSON objects specifying module name, inputs, and expected outputs:

cubic_polynomial.accepts json 
{ "cubic": { "x": [3], "Y": [35] } }
{ "cubic": { "x": [0], "Y": [5] } }
{ "cubic": { "x": [1], "Y": [7] } }

Running Tests

Using go-corset check bash 
# Check a single test case
echo '{ "cubic": { "x": [3], "Y": [35] } }' | \
  ./bin/go-corset check --batched - cubic_polynomial.zkasm

# Check multiple test cases from file
./bin/go-corset check --batched tests.accepts program.zkasm

# Debug a failing test with report
./bin/go-corset check --batched --report tests.accepts program.zkasm

Debugging Commands

Inspection and debugging bash 
# View compilation statistics
./bin/go-corset debug program.zkasm --stats

# View AIR constraints
./bin/go-corset debug program.zkasm --air

# Compile to binary constraints
./bin/go-corset compile program.zkasm -o output.bin

6. Comparison: gnark vs zkASM

Aspect gnark zkASM
Abstraction Level High-level DSL in Go Low-level assembly
Type System Single frontend.Variable type Explicit bit-widths (u1, u16, u256)
Overflow Handling Automatic (field arithmetic) Explicit (multi-value returns)
Control Flow Go control structures Labels and gotos
Assertions api.AssertIsEqual() if ... goto ... fail
Backend Groth16, PLONK AIR (custom prover)
Use Case General ZK applications zkEVM, custom protocols
When to use zkASM:
  • Building zkEVM or blockchain-specific circuits
  • Fine-grained control over constraint generation
  • Optimizing for specific field characteristics
  • Integration with Linea's proof system
